# 01 — 可用的结构化时间线搜索

**What to build:** 用户可以在浏览时间线标题栏中实时搜索当前标签页和最近浏览记录；结果保留浏览会话和标签页父子上下文，并提供清除、摘要及零结果反馈。

**Blocked by:** None — can start immediately.

**Status:** completed

- [x] 搜索框始终显示在时间线标题栏，宽屏与窄屏布局均可用。
- [x] 搜索覆盖当前标签页和最近浏览记录，并匹配标题、域名及完整网址。
- [x] 多个关键词使用忽略大小写的部分匹配和 AND 语义。
- [x] 搜索结果保留匹配历史记录所属会话。
- [x] 当前标签树保留匹配节点所需的祖先，并把非匹配祖先标记为上下文。
- [x] 搜索摘要只统计真实匹配项和包含匹配项的历史会话。
- [x] 零匹配与无浏览活动使用不同空状态，并能清除搜索。
- [x] 搜索词在视图切换和时间线刷新后保留，页面重新加载时重置。
- [x] 自动化测试通过已确认的时间线搜索模块接口验证用户可观察行为。

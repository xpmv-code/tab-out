# 01 — 云同步基础与连接 UI

Status: In progress

## 验收标准

- [ ] 默认未配置时，扩展不发出 Supabase 请求，现有收藏功能照常运行。
- [ ] 在被忽略的本地配置文件中填写项目 URL 和 publishable/anon key 后，可申请精确的 Supabase 域名权限。
- [ ] 用户可以请求邮箱 OTP、验证验证码、查看当前账号、手动同步和退出登录。
- [ ] 常用标签数据在本地优先保存；同步失败不阻断本地修改。
- [ ] 云端数据库 RLS 限制用户只能读取/插入/更新自己的文档。
- [ ] 冲突合并支持更新优先、删除墓碑、同组名归并及同网址去重。
- [ ] 自动化测试、JavaScript 语法检查、扩展 manifest JSON 校验和现有测试套件通过。
- [ ] README 说明 Supabase 控制台设置步骤及隐私边界。

## 实施说明

为第一阶段提交纯 JavaScript REST 客户端，避免在扩展页面加载第三方脚本或增加框架。真实部署和 OTP 邮件投递验证需等项目凭据配置后执行。
